# 台灣匹克球新手規則指南

繁體中文、無需建置的靜態網站。開啟 `index.html` 即可使用，也可部署到 GitHub Pages。

內容核對日期：2026-11-25。依 2026 USA Pickleball 規則與台灣總會公開入門資料整理，以傳統雙打計分為主；正式賽事依主辦規程。本網站為非官方教學整理。

## 功能

- 場地與斜對角發球圖解
- 發球、雙彈地、非截擊區、判線與失誤說明
- 可操作的雙打比分與站位練習，支援復原與重新開始
- 單打、每球得分制與比賽流程說明
- 情境問答、自我測驗與官方來源連結

## 本機預覽

```sh
python3 -m http.server 8000
```

## GitHub Pages

發布來源：`main` 分支根目錄 `/`。無外部套件、追蹤碼、API 或秘密金鑰。
私人 repository 的 Pages 需要相容的 GitHub 方案；一般個人帳號 Pages 網站仍為公開網站。

## 維護

每年規則更新時重新核對來源，再更新頁首與來源區的核對日期。勿將其他聯盟的發球或計分制度混入傳統規則。
